THREAT MODEL, IN PLAIN WORDS

The relay never sees the words.

  • Encrypted before upload. The host stores ciphertext and timestamps — never your messages.
  • Pinned transport. Clients verify the host certificate fingerprint before sending a token.
  • Revocable devices. Every device gets its own token; revoke one without touching the others.
  • Yours on disk. The full history lives in one SQLite file on this laptop.
NOTE Anyone with the vault passphrase and the database can read the history. Keep the passphrase off the host machine if that matters to you.
